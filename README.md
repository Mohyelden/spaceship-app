# سفينة الفضاء 🚀

تطبيق تعليمي لتلاميذ الصف الخامس: القسمة المطوّلة عبر مغامرة إصلاح محركات سفينة فضاء
(مبني بالكامل حسب وثيقة التصميم والسيناريو).

## التشغيل السريع

```bash
cd spaceship-app
npm install
npm run web        # يفتح في المتصفح: http://localhost:8081
npm start          # ثم امسح الـ QR بتطبيق Expo Go على الموبايل
```

> للتجربة على الموبايل: الجهاز والكمبيوتر على نفس شبكة الواي فاي.
> لو الصوت/الفيديو اتأخر على الويب: المتصفح يمنع التشغيل التلقائي، اضغط زر ▶ الكبير.

## مسار اللعبة

شعار (3 ثوانٍ) → تسجيل الدخول بالكود → فيديو القصة → خريطة الأقفال الثلاثة →
التمهيدي (مرحلة 1: بطاقات المستطيل 625÷5 · مرحلة 2: نموذج المستطيل 872÷4 ثم 1120÷4 + سؤال الاختيار) ⭐ →
المستوى الأول (الكابينة: اقسم ← اضرب ← اطرح ← نزّل · 625÷5) ⭐⭐ →
المستوى الثاني (782÷23) ⭐⭐⭐ → شاشة الإنجاز النهائية وانطلاق السفينة.

بنك المسائل متاح بجوار كل مستوى مفتوح وفي شاشات الإتمام (تدريب حر + نقاط XP + وسام ذهبي عند 100 XP).

## قواعد الدعم (نسختا البحث)

| الخطأ المتتالي في نفس الخطوة | التلقائية | عند الطلب 💡 |
|---|---|---|
| الأول | «حاول مرة أخرى ❌» | «حاول مرة أخرى ❌» |
| الثاني | يظهر التلميح 1 تلقائيًا | يضيء زر المساعدة ← يعرض التلميح 1 |
| الثالث | يظهر التلميح 2 تلقائيًا | زر المساعدة ← التلميح 2 |
| الرابع | تُحل المسألة ويُطلب «كرر المغامرة» بمسألة جديدة | نفس الشيء |

- النسخة الافتراضية من ملف `.env` (`EXPO_PUBLIC_HINT_MODE=on_demand` أو `auto`).
- **لوحة المعلم:** ضغطة مطوّلة (ثانية واحدة) على شعار الصاروخ في شاشة الدخول ←
  تغيير النسخة، نتائج كل تلميذ (صح/أخطاء/تلميحات/ضغطات المساعدة/حلول معروضة)، تصدير CSV، تصفير أو حذف تلميذ.

## الفيديوهات

زر «تخطي» مقفول في أول مشاهدة لكل فيديو لكل تلميذ، ويُفتح في المرات التالية.
الفيديوهات في `assets/videos` ويمكن إعادة توليدها من مجلد `../video-studio`.
